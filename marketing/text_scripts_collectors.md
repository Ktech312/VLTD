## KEY RULES FOR COLLECTOR TEXTS

1. **AI is a feature here — use it.** Collectors want smart, precise, verifiable.
2. **Lead with value to the collection**, not the product.
3. **Be direct.** Collectors are practical. Skip the story, get to what it does.
4. **Personalize.** You know these people — reference their collection if you can.
5. **Texts should be short.** 2–3 sentences. The link does the explaining.

## HOW TO HANDLE REPLIES

**"How does the AI work?"**
> You photograph a piece — card, comic, signed item, whatever — and it automatically identifies it, reads any text on it (barcodes, labels, certificates), and builds a complete catalog entry. All stored securely. You can export the whole collection as a spreadsheet or pull individual certificates as PDFs.

**"Can it handle [specific type of collectible]?"**
> Yes — anything you can photograph. The scanning reads visual details and any text on the item. Works best for items with clear labels, barcodes, or printed info, but it builds a solid record from any photo.

**"Is it accurate?"**
> Really solid for identification and text reading. I'd say it gets the details right 90%+ of the time, and you can always edit the entry manually if something's off. The certificate is always accurate because you control what goes into the final record.

**"What does it cost?"**
> Free to start — up to 25 items. Pro is $9/month for unlimited. Right now I'm giving founding users Pro for free while I'm testing it. You'd be in that group.

**"What about insurance / resale value?"**
> That's actually one of the main use cases. A documented record with a certificate of authenticity is exactly what insurers and serious buyers want to see. It's not a replacement for professional appraisal, but it's the foundation every collection should have.
